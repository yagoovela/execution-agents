Inside a 2,337-line helpers.ts that is not pure — the same file B2 had to extract singleConditionCheck from.

When a node completes, the back walks the edges leaving it and, for each one, decides which field of the source the handle stands for, then writes a { id, label, text } entry into the target's *Data array (addConnectToNodes → givingDataToNode / getOutputByType, helpers.ts:20).

B3 first read this as a transform and left it in the back. It is field selection by handle: a pure function of the edge, the source's output and the loop iteration, over data both writers already store in node_executions.outputData. It lives in the back only because the loop does.
