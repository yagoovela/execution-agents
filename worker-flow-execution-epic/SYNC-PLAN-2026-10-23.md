## Steps

Run them in order, in one branch, after the team agrees on the restructure.

1. **Merge the spec PR into `main`.** The change is structural (new tasks, new dependencies), so it
   lands before implementation, not at the end with the code PRs.
2. **Generator content modules.**
   1. Add `w5_a11.py`, `w5_a13.py`, `w5_a14.py` and `w5_a6b.py`, modelled on `w5_a7.py`.
   2. Rewrite `w5_a7.py` for the widened scope and the settled decisions.
   3. Patch `w4_b3b4.py` (B4 flag text), `w6_c2.py` (loop deletion), `w5_b5.py` and `w5_b6.py`
      (dependencies, back-only list).
   4. Use file and symbol references only (MAINTENANCE §3c).
3. **Order and titles.** Add the four tasks to `order.py` in Wave 5, in the order
   A11 → A13 → A7 → A14 → A6b → B5 → B6 → B7, and to `TITLES_ALL.py` in both languages.
4. **Rebuild.** Run every `build_w*.py` / `w*_build.py` script (MAINTENANCE §1).
5. **Hand-written pages.** Patch, in both languages: `delivery-waves.html` (Wave 4 flag, Wave 5
   table, Wave 6), `epic-handbook.html` (task count, dependency graph), `scale-readiness-review.html`
   and `arquitetura-v2-complemento.html` (any mention of A7's two callbacks or of the B4 flag being
   per flow), `timeline/index.html` (new tasks). Check every restated number by hand in both
   languages; `lang_scan.py` does not compare what the two sides say.
6. **Checks.** Run `reconcile_facts.py`, `lang_scan.py` (triage against the 36-hit baseline), and
   render the changed pages: no overflow, no missing translation, no broken link. Plant one wrong
   fact and confirm `reconcile_facts.py` goes red before trusting it green.
7. **Publish to `execution-agents`.** Copy the rebuilt and patched pages, run
   `_assets/link_header_css.py` then `_assets/unify_header.py`, and restore every page you did not
   change (`unify_header.py` rewrites all of them). Open the PR there.
8. **Verify the mirror.** Run `verify_publish_sync.py`; expect `MISSING` for the four new tasks
   before publishing and `OK` after. Run `--refresh` only after both sides are confirmed equal.
9. **ClickUp.** Draft, then create after confirmation:
   - cards for A11, A13, A14 and A6b under the Wave 5 parent, with dependencies;
   - the A7 description rewritten (fix its spec link to `.claude/tasks/...`);
   - the Wave 5 parent's children list and order;
   - the A6 and A3 cards: a comment that their open gaps moved to A7.
10. **Estimates.** Add A11, A13, A14 and A6b, and the widened A7, to
    `~/enhanced/timeline-worker-refactor.txt`.

## Risks

- **A partial publish.** Publishing the generated pages without the hand-written ones leaves
  `delivery-waves.html` describing the old Wave 5. Steps 5 and 7 ship together.
- **Header loss.** Skipping `unify_header.py` strips the shared navigation from every rebuilt page
  (MAINTENANCE §3b).
- **Laundered drift.** Running `verify_publish_sync.py --refresh` before step 7 hides the drift
  instead of fixing it.
